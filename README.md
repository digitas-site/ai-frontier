# AIフロンティア（次世代AI研究会）公式サイト

AIを使ってエージェントやシステムをつくる人が集まる研究会のサイトです。
運営：株式会社デジたす

## ファイル構成

```
index.html        … ページ本体（文章の修正はここ）
css/style.css     … 見た目（色・文字・配置）
js/main.js        … 会員登録フォームの動き
js/config.js      … 登録データの保存先URL（ここだけ書き換えればOK）
assets/logo.png   … ロゴ（背景透過）
assets/icon.png   … ブラウザのタブに出るマーク
gas/Code.gs       … 登録データをGoogleスプレッドシートに保存する仕組み
```

## 1. まず見た目を確認する（GitHub Pages）

1. GitHubで新しいリポジトリを作成（例：`ai-frontier`）
2. このフォルダの中身をすべてアップロード
3. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
4. 1〜2分後に `https://<ユーザー名>.github.io/ai-frontier/` で表示されます

この段階では会員登録は「お試しモード」です。送信しても保存されず、完了画面にその旨が表示されます。

## 2. 会員登録を本番にする（Googleスプレッドシートに保存）

例えるなら「サイトの登録フォーム＝ポスト」「スプレッドシート＝名簿ノート」。
Google Apps Script が、ポストに届いた手紙を名簿に書き写す係です。

1. Googleドライブで新しいスプレッドシートを作成（名前例：AIフロンティア会員名簿）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からあるコードを消し、`gas/Code.gs` の中身を貼り付けて保存
   - 運営に通知メールを送りたい場合は `NOTIFY_TO` にアドレスを入れる
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Googleアカウントの許可画面で許可
6. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec`）をコピー
7. `js/config.js` の `ENDPOINT: ""` の "" の中に貼り付けて、GitHubに反映

以後、登録があるとスプレッドシートの「会員」シートに1行ずつ追加され、登録者には確認メールが届きます。
同じメールアドレスでの二重登録は自動で弾きます。

> Apps Script のコードを直したときは、「デプロイを管理」→ 編集 →「新バージョン」で更新してください（URLは変わりません）。
